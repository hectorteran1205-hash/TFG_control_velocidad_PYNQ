# Código fuente

Este directorio contiene los archivos de programación desarrollados para
el Trabajo Final de Grado en Ingeniería Electrónica Industrial y Automática:
Diseño e implementación de un sistema de control de velocidad de un motor de 
corriente continua mediante la placa PYNQ.

El código se organiza en los siguientes bloques:

- Hardware descrito en VHDL.
- Archivos del overlay para la PYNQ-Z2.
- Servidor Python y Flask.
- Interfaz gráfica desarrollada en React.
- Programas de adquisición y análisis realizados en MATLAB.
