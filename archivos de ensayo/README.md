# Datos experimentales

Este directorio contiene los archivos CSV obtenidos durante la validación
experimental del sistema de control de velocidad.

Los datos se organizan según los siguientes ensayos:

- Identificación dinámica del conjunto motor-L298N.
- Seguimiento de velocidad con controladores P, PI y PID.
- Comparación experimental de los controladores.
- Respuesta del sistema ante perturbaciones de carga.

Los archivos se conservan para permitir la consulta, representación y
repetición del análisis presentado en la memoria del TFG.
